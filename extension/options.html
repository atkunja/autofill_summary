Your experience

AI drafts use your experience, goals, and enabled projects. Contact fields and the attachment are excluded, but any contact details inside extracted text are included. Review the text before saving.

Your projects

Save project links and describe what you built. Read project link imports a public webpage or a GitHub repository README; it does not crawl the whole site or repository. Review the source text and add missing details.

Reading a link contacts that site without your API key. Chrome asks for access to that source. Enabled projects are sent to OpenAI only when you generate an answer.

Optional AI drafts

Generation sends your experience, goals, enabled project notes and source text, selected question, and the job context you provide to OpenAI. API usage is billed to your OpenAI account.
